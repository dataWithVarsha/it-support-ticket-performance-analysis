# IT Support Ticket Performance Analysis

## 📊 Project Overview

This project is a Power BI dashboard created to analyze IT support ticket performance.

The dashboard helps understand ticket status, priority, resolution time, SLA performance, and customer satisfaction.

I created this project to improve my practical skills in Power BI, DAX, Data Analysis, and Dashboard Design.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel
- GitHub

## 🎯 Project Objectives

- Analyze total and resolved tickets
- Understand ticket status and priority
- Analyze ticket resolution time
- Track SLA performance
- Analyze customer satisfaction
- Identify useful business insights

## 📑 Dashboard Pages

1. **Overview** – Overall ticket performance
2. **Ticket Analysis** – Ticket status, priority, and category
3. **Customer Analysis** – Customer-related ticket analysis
4. **SLA & Resolution** – Resolution time and SLA performance
5. **Customer Satisfaction** – Customer satisfaction analysis
6. **Insights & Action Recommendations** – Key findings and recommendations
7. **Customer Details** – Detailed customer-level information
